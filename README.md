# NightStint

Retro pixel GT endurance racing. Day turns to night, headlights on, hypercars closing in, damage piling up.

Live: https://lhcars.my/NightStint/

Root = built game (Vite, base /NightStint/). Source in `source/` (`src/engine.ts` is the shared LH Cars Arcade engine, `src/main.ts` is the game).
